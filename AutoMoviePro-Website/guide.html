Google Storage ওয়েবসাইট

ইনস্টল, সেটআপ ও স্টোরেজ

নন-টেক ইউজারদের জন্য সহজ ধাপ। ভিডিও তৈরির পর অডিও–ভিডিও–মেটা আলাদা করে সংরক্ষণ এবং Google Drive অ্যাকাউন্ট রোটেশন।

সূচি ১) সফটওয়্যার ইনস্টল ২) চ্যানেল ও API ৩) অ্যাসেট আলাদা রাখা (Audio / Video / Metadata) ৪) Google Storage অটো কানেক্ট ও রোটেশন ৫) কম্প্রেশন ও প্রাইভেট সার্ভার মাইগ্রেশন

১) সফটওয়্যার ইনস্টল

  1. WhatsApp থেকে পাওয়া লিংক দিয়ে AutoMoviePro-Setup.exe ডাউনলোড করুন।
  2. ইনস্টলার চালান (বা জিপ আনজিপ করে START.bat)।
  3. অ্যাপে Login ID ও Password দিন (WhatsApp মেসেজে পাঠানো)।
  4. PC চালু রাখুন — নির্ধারিত সময়ে ভিডিও জেনারেট ও আপলোড হবে।

২) চ্যানেল ও API

  1. Channel: নিশ, আপলোড টাইম, লোগো/ইন্ট্রো, YouTube/Facebook Connect (once)।
  2. Settings → API: প্রয়োজনীয় কী (Agent Collect দিয়েও করা যায়)।
  3. Google AI Studio-তে প্রতি ভাষার ভয়েসের জন্য আলাদা কী স্লট ব্যবহার হয়; ইংরেজি দরকার হলে রোটেশন।

৩) অ্যাসেট আলাদা রাখা কেন?

প্রতিটি ক্লিপ এখন তিন ভাগে ভাগ হয় — পরে একই অডিওতে নতুন ভিডিও বসানো যায় (hot-swap):

  • {id}_audio.m4a — শুধু ভয়েস
  • {id}_video.mp4 — শুধু ছবি (অডিও ছাড়া)
  • {id}_metadata.json — স্ক্রিপ্ট, ট্যাগ, সময়, ইউজার

লোকাল ফোল্ডার: অ্যাপের output/asset_vault/। আপলোডের আগে HEVC/AAC/WebP কম্প্রেশন হয়।

৪) Google Storage — অটো কানেক্ট ও রোটেশন

ফ্রি Google অ্যাকাউন্টে সাধারণত ~১৫GB থাকে। সিস্টেম ১৪GB পূর্ণ হলে পরের অ্যাকাউন্টে স্যুইচ করে। কোন ফাইল কোন ইমেইলে আছে — ডাটাবেসে ম্যাপ থাকে।

A) Google Cloud / Drive প্রস্তুতি (একবার প্রতি অ্যাকাউন্ট)

  1. Google Cloud Console খুলুন → প্রজেক্ট তৈরি।
  2. APIs & Services → Enable APIs → Google Drive API চালু করুন।
  3. দুই পথের যেকোনো একটা:

পথ ১ — OAuth (সাধারণ Gmail) — সহজ

  1. Credentials → Create → OAuth client ID (Desktop app)।
  2. লোকাল টুলে সাইন ইন করে token.json / authorized-user JSON সংরক্ষণ করুন।
  3. অ্যাপে Settings বা API দিয়ে সেই JSON পেস্ট করুন (ইমেইল + credentials)।

পথ ২ — Service Account (অ্যাডভান্স)

  1. Service account তৈরি → JSON কী ডাউনলোড।
  2. Drive-এ একটি ফোল্ডার বানিয়ে সেই সার্ভিস অ্যাকাউন্ট ইমেইলে Editor শেয়ার করুন।
  3. অ্যাপে folder_id (ফোল্ডার URL-এর ID) দিন।

B) অ্যাপে কানেক্ট (Desktop)

  1. অ্যাপ লগইন করুন।
  2. একাধিক Google অ্যাকাউন্ট যোগ করুন — API: POST /api/drive-accounts বডি উদাহরণ:
{
  "email": "storage1@gmail.com",
  "label": "Vault A",
  "folder_id": "1abc...DriveFolderId",
  "credentials_json": "{ ... OAuth token or service account JSON ... }"
}
  1. স্ট্যাটাস দেখুন: GET /api/drive-accounts — active email ও GB ব্যবহার।
  2. রিফ্রেশ কোটা: POST /api/drive-accounts/{id}/refresh।
  3. ভিডিও জেনারেট/লোকালাইজ শেষে অটো আপলোড (বন্ধ করতে: এনভ AMP_DRIVE_UPLOAD=0)।

C) রোটেশন কীভাবে কাজ করে

  • Active অ্যাকাউন্টের ব্যবহার ≥ ১৪GB → পরের কানেক্টেড অ্যাকাউন্ট।
  • প্রতিটি অ্যাসেট ম্যাপ: asset_id → Google email (SQLite asset_locations)।
  • সব অ্যাকাউন্ট ভর্তি হলে আপলোড থামে — নতুন অ্যাকাউন্ট যোগ করুন।

৫) কম্প্রেশন ও প্রাইভেট সার্ভার

  • ভিডিও: HEVC (libx265) CRF ~৩০ — না গেলে x264।
  • অডিও: Opus অথবা AAC ~৮০kbps (কথা)।
  • পোস্টার: WebP।
  • migration_ready=1 মানে Drive-এ সেভ হয়ে গেছে।
  • প্রাইভেট সার্ভারে কপি: এনভ AMP_LOCAL_ASSET_ROOT=D:\PrivateVault সেট করুন — প্রতি ~৩০ মিনিটে সিঙ্ক, বা POST /api/assets/local-sync।
টিপস
  • Google AI Studio API ≥২টি; Agnes ও অন্যান্য প্রয়োজনীয় কী দিন।
  • শর্ট সর্বোচ্চ ~২ মিনিট, লং ~৫ মিনিট।
  • স্টোরেজ আলাদা রাখুন — AI কী ও Drive ক্রেডেনশিয়াল মিক্স করবেন না।
