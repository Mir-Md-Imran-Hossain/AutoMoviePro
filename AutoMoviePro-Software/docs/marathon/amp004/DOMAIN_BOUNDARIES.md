---

## Audio boundary (explicit freeze)

Future audio = Dialogue + SFX + Music + Ambience + Mixing + Ducking + Loudness + Timeline sync  

TTS dialogue **সম্পূর্ণ audio system নয়**।

---

## Script boundary (explicit freeze)

Future independent domain: topic fit, hook, structure, pacing, retention, factual grounding, claim support, natural language, emotional progression, visual/audio/localization/subtitle feasibility — creative aggregation still via 04F.

---

## Visual boundary (explicit freeze)

Semantic correctness · entity · object state · action · spatial · temporal · continuity · technical · artifact verification  

Future detection list (architecture requirement, not implemented): object substitution/duplication/disappearance, impossible simultaneous actions, wrong actor/object, transformation, phone/camera confusion, wrong tool, impossible interaction, posture/location mismatch, environment/wardrobe/lighting/camera drift, flicker, motion deformation.

---

## Localization boundary

Meaning preservation — not word substitution। Tone, terminology, speaker, timing, density, reading speed, line breaks, placement, cultural naturalness।

---

## Text / VFX principle

**EFFECTS MUST HAVE PURPOSE** (emphasis / transition / information / emotion / spatial / pacing)। Random zoom/shake/glow নিষিদ্ধ as default।

---

## FFmpeg boundary

FFmpeg = render engine। Stream map, filtergraph, timebase, duration, FPS, resolution, SAR/DAR, codec, pix_fmt, sample rate, layout, subtitle integration, atomic output, temp artifacts, container integrity = **formal contracts** (implement later — rewrite now নয়)।
